# kulbit-maker

Генератор смешных названий для команды.

```
python kulbit.py          # одно название
python kulbit.py -n 10    # десять разных
python kulbit.py -i       # интерактивно: Enter — ещё, q — выход
```

## Правила
- два **разных** слова из `words.json`;
- слова-пары (`buddy`) всегда идут только вместе: «тралалалэла» + «бравл старс», «жгс» + «я кондитер пеку торты»;
- 45% — с предлогом и правильным падежом: «абманка для абамки», «сквиш против доты», «об аниме», «со сквишем»;
- 15% — прилагательное + слово в нужном роде: «майнкрафтовая абамка», «анимешное итмо»;
- остальное — просто два слова: «майнкрафт кульбит»;
- в 25% случаев специально подбираются созвучные слова (абамка/абманка);
- 5% — сиквел: «дота vs итмо 2», «кульбит remastered».

Новые слова добавляются в `words.json` (нужны падежи и род; прилагательное — по желанию).
